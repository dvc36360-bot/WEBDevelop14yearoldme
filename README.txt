WEBWINKEL WEBSITE
=================

Files:
- index.html       Home page
- about.html       About WebWinkel and founder photo
- services.html    Current services
- pricing.html     Packages and supplied pricing
- faq.html         Expandable FAQ
- contact.html     Quote enquiry form
- styles.css       Responsive design
- script.js        Navigation, FAQ and enquiry form behaviour
- config.js        Optional contact setup
- assets/          WebWinkel logo crop and founder photo

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. For GitHub Pages, upload all files and the assets folder into the repository root.
4. In GitHub, enable Pages for the correct branch/folder.

CONTACT SETUP
Open config.js.
- whatsappNumber: add an approved business WhatsApp number using international digits only, e.g. 27XXXXXXXXX. Do not publish a personal number without parent/guardian approval.
- contactEmail: add an approved business email address.
The contact form does not save submissions to a database. It opens WhatsApp or email only after one of these details is configured. If neither is configured, it prepares a message that can be copied.

IMPORTANT ACCURACY NOTES
- No demo projects or made-up client work are included.
- No fake testimonials are included.
- Advanced admin dashboards are not advertised as a current service.
- Google Sheets integration is described as subject to project requirements.
- The website is a static front-end; GitHub Pages does not run a private backend.
- Check all pricing, hosting arrangements and payment terms before publishing.
- The original price list mentions EFT and cash. PayPal is described as not currently available.
- The R250 multipage upgrade is represented as R400 + R250 = R650.

PRIVACY
The founder photo was included because the owner requested it for the About page.
Review the public site with a parent/guardian before publishing, especially contact details and personal information.
